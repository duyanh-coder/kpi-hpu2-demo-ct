# HPU2 baseline from CTU source

This prototype keeps the CTU application structure and UI as the baseline.

Implemented:
- HPU2 logo and university identity.
- HPU2 primary color theme.
- Existing CTU dashboard and charts preserved.
- Priority HPU2 pages: Annual Work Plan and Task Assignment.
- Existing KPI Registration and Evaluation flows retained.
- Mobile sidebar closes after selecting a submenu item.
- Header/search behavior adjusted for small screens.

Excluded from package:
- node_modules
- .next
- .git
